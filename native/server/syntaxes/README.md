# Native syntax definitions

Precompiled newline-aware grammars for syntect’s existing fancy-regex engine, from two-face revision `33f7e243b6174e8f0c63fd7698ec5736d715e355`. Upstream includes bat’s broad language collection. This is bundled grammar data, not a runtime dependency. Individual grammar licenses are retained in LICENSES.md.

Source: https://github.com/CosmicHorrorDev/two-face/tree/33f7e243b6174e8f0c63fd7698ec5736d715e355/generated

To update, replace syntaxes.bin with generated/syntaxes-fancy-newlines.bin and LICENSES.md with generated/acknowledgements_full.md from the same revision, then run the native highlighting tests.
