# Rust models with React views

Application behavior belongs in Rust. The native core and server own persistence, provider execution, and repository operations; `native/presentation` owns shared workbench transitions, renderer projections, transcript reconciliation, and liquid simulation. React/Octane components retain typed TSX for rendering and browser interaction. The presentation crate also compiles to WebAssembly so typing, selection, and animation can use Rust synchronously without a server request per interaction. Its generated bindings and contracts live under `build/presentation`; the renderer build regenerates them. New application models belong in Rust, with generated TypeScript contracts consumed by the views. React components, local UI state management, browser adapters, and build tooling remain TypeScript. Views import generated contracts using their canonical Rust names; a distinct view model name is warranted only when its shape differs.
